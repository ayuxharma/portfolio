# Developer Portfolio

A standalone portfolio website built with HTML, CSS, and vanilla JavaScript.

## Edit the website

Open `index.html` in GitHub's editor or any code editor. The page code is contained in that file, while the About portrait is stored at `assets/ayush-portrait.jpg`.

The portfolio is filled with Ayush Sharma's current content. Project descriptions and links are stored in the `projectData` object near the bottom of `index.html`.

MiniRaftKV and Hospital Bedside Sign Recognition currently show a “links will be added” note. Add their URLs to the corresponding `github` and `demo` fields when those projects are ready to share.

## Preview locally

Double-click `index.html` to open it in a browser. No build process or dependencies are required.

## Publish with GitHub Pages

Upload `index.html` and the `assets` folder to the root of a GitHub repository, then enable GitHub Pages for the repository's main branch. GitHub will serve this file as the homepage.

## Optional files

When the résumé is ready, add its URL or filename to the contact section and replace the “Resume — coming soon” text with a link.
